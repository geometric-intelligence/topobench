SheafTSP — Architecture Diagrams

Companion to sheaf_tsp_overview.html. The frozen submission configuration is summarized in Sec. 3. Color code: sheaf-diffused signal (operator-normalized)   exact count term (kept normalization-free)   loss-side regularizer.

1. End-to-end data flow

Input graph
$N$ nodes, 15-d features, inductive family (50–300 nodes)
↓
Preprocessing transform (cached with the dataset)
CellCliqueLifting: all 3-cliques as 2-cells (canonical set, invariant under relabeling) → $x_0, x_1, x_2$, incidences $B_1, B_2$ (unsigned, $\{0,1\}$), Hodge Laplacians $L_\downarrow, L_\uparrow$
↓
AllCellFeatureEncoder (width 64, fixed by challenge)
per-rank linear encoders; ranks {0, 1}
↓
SheafTSP backbone — ×3 layers on 1-cells (detail in Sec. 2)
learned sheaf Laplacian $\hat L_{\mathcal F}$ → polynomial spectral filter → $x_1'$
+ per-layer transport regularizer → task loss (dashed, Sec. 2)
↓
Node embedding assembly (one tensor, three additive terms): $x_0 = \color{#2b6cb0}{B_1 x_1' + x_0^{\text{enc}}} + \color{#2f855a}{W_{\text{tri}}\, t_v}$
blue terms: sheaf-diffused signal (boundary propagation + encoder residual). green term: linear embed of the exact count signal derived from the complex's own incidences, $t_v = |B_1||B_2|\mathbf 1$ ($\sum_v t_v = 6\cdot\#\triangle$ under the clique lifting; zero-init with a warm-start channel, tri_warm). No normalization is applied to $x_0$ (residual_connections: false) — the load-bearing invariant: any LayerNorm here erases the count magnitudes.
↓
Readout: PropagateSignalDown ($x_1 \to x_0$ mix) → linear head; node-level tasks read $x_0$ directly, graph-level tasks sum-pool it first
every operation from $t_v$ to the prediction is linear, so the pooled green term stays exactly proportional to the triangle count

2. Inside one SheafConvLayer

$x_1 \in \mathbb R^{N\times C}$   (1-cell features; $N$ = #edges of the graph = nodes of the sheaf)
↓
learned geometry
dropout$_{\text{mlp}}$(x) → Restriction-map MLP
surgical regularization: dropout is applied to the restriction-map input only; the filtered signal receives none (mlp_dropout: 0.5)
↓
antisymmetrized skew $S_{uv} = -S_{vu}$ → Cayley $R_e = (I{-}S)(I{+}S)^{-1} \in SO(d)$
$R_{vu} = R_{uv}^{-1}$ by construction — orientation-equivariant, invariant to node relabeling
↓
Gaussian kernel $k_{ij} = \exp(-\rho_{ij}^2 / 4t)$, learnable $t$
default $\delta^2$: transport-inconsistency $\lVert s_i - R_e s_j\rVert^2$; feature distance available (kernel_distance)
signal
Stalk lift $s = \mathrm{Lift}(x_1) \in \mathbb R^{Nd\times C}$
each stalk coordinate gets distinct channel content
waits for $\hat L_{\mathcal F}$…
↓
Sheaf Laplacian $L_{\mathcal F} = \delta^\top K \delta$ → $\hat L_{\mathcal F} = D^{-1/2} L_{\mathcal F} D^{-1/2}$, spectrum $\subseteq [0,2]$
↓
Spectral filter — default: PPR scalars on $P = I - \tfrac12\hat L$, $K{=}10$, $w_k = \alpha(1-\alpha)^k$ init
alternatives in the codebase: monomial $\sum_k \hat L^k s W_k$ ($W_0{=}I$ init), Chebyshev $T_k(\hat L{-}I)$
↓
stalk pooling $(N, dC) \to (N, C)$ → + residual → LayerNorm → $x_1'$
meanwhile, loss-side:
Transport regularizer ($\lambda = 0.01$, signal detached — gradients only into $R$, $t$): Dirichlet $\mathrm{tr}(s^\top L_{\mathcal F} s)$  or  kernel alignment $-\overline{\exp(-\lVert s_i - R_e s_j\rVert^2/4t)}$
the alignment term is bounded per edge, so high-dissimilarity (cross-community) edges contribute at most a fixed gradient magnitude

3. Submission configuration

The frozen configuration, with the rationale each choice carries. Research options retained in the codebase (default off) are documented in the config comments and the experiment log.

Invariants the configuration protects: an operator-normalized diffused signal for community structure, a strictly sum-linear count term for triangle regression, and regularization confined to the learned geometry.
